# הכסף שלי

אתר משפחתי לניהול הכסף של הילדים: עבודות, הכנסות, חובות, תקבולים, הוצאות ויעד חיסכון.

- `index.html`, `app.js` — האתר (נפתח בדפדפן, בלי התקנה).
- `config.js` — כתובת הפרויקט ב-Supabase ומפתח ציבורי (publishable/anon). **אין לשים כאן מפתח service_role או secret.**
- `tests.html`, `tests.js` — בדיקות קבלה מול השרת, במשפחת בדיקה נפרדת.
- `schema.sql` — מבנה המסד, ההרשאות והפונקציות. מריצים פעם אחת ב-Supabase SQL Editor.

הנתונים עצמם נשמרים ב-Supabase ומוגנים בהרשאות שבמסד. הקוד הזה לא מכיל פרטים של משפחה, סיסמאות או מפתחות סודיים.
האפליקציה אינה חשבון בנק ואינה מעבירה כסף.
